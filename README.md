# GARMENTLy

**Your intelligent digital wardrobe.**

GARMENTLy is an AI-powered virtual closet that helps users organize their clothing, understand garment-care requirements, and create personalized outfits using pieces they already own.

Users can photograph their garments and care labels, store them in a private digital wardrobe, receive AI-generated clothing-care guidance, and generate outfit recommendations based on their personal collection.

---

## Overview

Most people own clothing they forget about, wash incorrectly, or struggle to combine into complete outfits.

GARMENTLy turns an existing wardrobe into an organized and intelligent clothing-management system. The platform combines image analysis, garment information, care guidance, and personalized outfit generation in one application.

---

## Features

### Digital Wardrobe

- Upload and organize clothing items
- Store garment names, brands, categories, colors, and materials
- View every garment through a personalized dashboard
- Edit or remove items from the wardrobe

### AI Garment Analysis

- Analyze garment photographs using Gemini AI
- Extract useful clothing details
- Identify likely materials and garment categories
- Generate washing and care recommendations
- Suggest appropriate detergent and drying methods

### Care-Label and Barcode Scanning

- Upload photographs of clothing-care labels
- Scan supported garment barcodes
- Use available product information to improve garment identification

### AI Catalog Photos

- Generate cleaner catalog-style garment images
- Create a more consistent and visually organized digital closet

### Personalized Outfit Generation

- Generate outfits using garments already owned by the user
- Select clothing based on occasion, style, and preferences
- Prevent recommendations from including items outside the user's closet
- Save generated outfits for future reference

### Private User Accounts

- Secure account creation and authentication
- Private wardrobe data for each user
- Protected garment-image storage
- Supabase Row Level Security for database access

### Responsive Interface

- Designed for desktop and mobile use
- Premium dark interface with neutral and gold accents
- Simple navigation across the wardrobe, outfit generator, and saved outfits

---

## How It Works

1. Create a GARMENTLy account.
2. Upload a garment photograph and optional care-label image.
3. Allow the AI to analyze the garment.
4. Review and save the garment information.
5. Continue building a private digital wardrobe.
6. Generate personalized outfits from saved clothing.
7. Save favorite outfits for later use.
